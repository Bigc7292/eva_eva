## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to security@toploader.ai. All security vulnerabilities will be promptly addressed.

Please do not disclose security vulnerabilities publicly until they have been handled by the security team.

The security team will acknowledge receipt of your vulnerability report and will send you regular updates about our progress. If you're curious about the status of your disclosure please feel free to email us again.

## Security Measures

This project implements the following security measures:

1. Regular dependency updates to patch known vulnerabilities
2. Code scanning for security issues
3. Secure authentication and authorization mechanisms
4. Data encryption for sensitive information
5. Input validation and sanitization
6. Regular security audits
